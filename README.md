# ClubeON CCP — Sistema de Transmissão Digital Multi-Telas

O ClubeON CCP é uma plataforma de transmissão digital desenvolvida para resolver um problema operacional real: a necessidade de atualizar manualmente anúncios e comunicados em múltiplos monitores e PDVs utilizando pendrive/USB.

O objetivo do projeto foi centralizar completamente o gerenciamento de conteúdos e permitir atualização remota e sincronizada das telas em tempo real.

## Problema Resolvido

Antes do sistema:

* Era necessário ir monitor por monitor para atualizar conteúdos
* O processo consumia tempo operacional
* Existia risco de conteúdos desatualizados
* Não havia sincronização entre telas
* A operação dependia de atualização manual física

Com o ClubeON CCP:

* As apresentações são gerenciadas centralmente
* Os conteúdos sincronizam automaticamente
* As telas atualizam em tempo real
* Não é mais necessário acesso físico aos dispositivos
* Múltiplos terminais podem operar simultaneamente

## Principais Funcionalidades

* Gerenciamento centralizado de apresentações
* Upload de imagens e vídeos
* Sincronização em tempo real
* Controle de múltiplos terminais
* Atualização automática das telas
* Fullscreen automático
* Suporte PWA
* Compatibilidade com TV Box Android
* Compatibilidade com Smart TVs
* Sistema de apresentações independentes por terminal
* Player otimizado para exibição contínua

## Objetivo do Projeto

Criar uma solução profissional de Digital Signage capaz de:

* reduzir tempo operacional
* automatizar transmissões
* facilitar gerenciamento de campanhas
* permitir controle remoto das telas
* modernizar comunicação interna empresarial
